# Triage labels

| Canonical role    | Local status       | Meaning                                |
| ----------------- | ------------------ | -------------------------------------- |
| `needs-triage`    | `needs-triage`     | Maintainer must evaluate the ticket    |
| `needs-info`      | `needs-info`       | Waiting for more information           |
| `ready-for-agent` | `ready-for-agent`  | Fully specified and ready to implement |
| `ready-for-human` | `ready-for-human`  | Requires human implementation          |
| `wontfix`         | `wontfix`          | Will not be actioned                    |

When a skill refers to a canonical role, use the matching local status.
