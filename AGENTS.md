## Agent skills

### Issue tracker

Specifications and implementation tickets are tracked as Local Markdown. StayPane currently keeps its PRD under `.scratch/` and its aggregate implementation queue in `tickets.md`; external pull requests are not currently a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The repository uses the standard `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

StayPane uses a multi-context domain-document layout. See `docs/agents/domain.md`.
